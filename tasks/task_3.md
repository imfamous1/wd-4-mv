# Практическое задание 3: Игра-платформер на JavaScript

## Описание задания

Создайте веб-игру в жанре платформер (platformer) с использованием JavaScript. Игра должна быть полностью функциональной, включать управление персонажем, физику движения, коллизии и игровую механику.

### Требования к игре

Игра должна содержать основные элементы платформера:

- Управляемый персонаж (прыжки, движение влево/вправо)
- Платформы и препятствия
- Система коллизий (столкновения)
- Система подсчета очков или прогресса
- Условия победы/поражения (опционально)
- Несколько уровней или бесконечный режим (на выбор)

## Технические требования

### Выбор технологий

**Основной стек:**
- HTML5 Canvas API (рекомендуется) или DOM-манипуляции
- CSS для стилизации интерфейса
- Vanilla JavaScript (чистый JavaScript)

**Допустимые библиотеки и инструменты:**

- Canvas API для отрисовки графики
- Игровые библиотеки (Phaser.js, Matter.js для физики — опционально)
- Аудио библиотеки для звуковых эффектов (опционально)
- Любые другие библиотеки по согласованию

**Важно:** Основная логика игры должна быть реализована на чистом JavaScript. Библиотеки можно использовать для упрощения работы с графикой или физикой, но не для замены всей игровой логики.

### Обязательное требование: использование нейросетей

Задание **обязательно** должно быть выполнено с использованием нейросетей. Допустимые инструменты:

- DeepSeek
- ChatGPT
- Perplexity
- Cursor
- Другие аналогичные инструменты

**Важно:** В игре или в файле README необходимо указать:
- Какую нейросеть вы использовали
- Сколько времени заняло выполнение задания
- Какие части игры были созданы с помощью нейросети

### Требования к функционалу

#### Обязательные элементы:

1. **Управление персонажем:**
   - Движение влево/вправо (клавиши A/D или стрелки)
   - Прыжки (клавиша Space или W)
   - Плавная анимация движения

2. **Игровая физика:**
   - Гравитация
   - Коллизии с платформами
   - Обработка столкновений

3. **Игровой интерфейс:**
   - Отображение счета/очков
   - Индикатор здоровья (опционально)
   - Кнопки управления (старт, пауза, рестарт)

4. **Игровая логика:**
   - Система подсчета очков
   - Условия завершения уровня/игры
   - Обработка игровых событий

#### Дополнительные возможности (для повышения оценки):

- Несколько уровней с разной сложностью
- Сбор предметов (монеты, бонусы)
- Враги или препятствия
- Система сохранения прогресса (localStorage)
- Звуковые эффекты и музыка
- Анимации персонажа и объектов

## Архитектура проекта

### Рекомендуемая структура файлов:

```
index.html          - основной файл с canvas или игровым контейнером
js/
├── main.js         - главный файл, инициализация игры
├── Game.js         - основной класс игры (управление игровым циклом)
├── Player.js       - класс персонажа (движение, физика)
├── Platform.js     - класс платформы
├── Collision.js    - система обработки коллизий
├── InputHandler.js - обработка пользовательского ввода
└── Renderer.js     - класс для отрисовки (опционально)
css/
└── style.css       - стили для интерфейса игры
assets/             - ресурсы (изображения, звуки - опционально)
├── images/
└── sounds/
```

**Примечание:** Структура может быть изменена в зависимости от выбранного подхода и используемых библиотек.

## Требования к реализации

### Игровой цикл

Игра должна использовать игровой цикл (game loop) с обновлением состояния и отрисовкой:

```javascript
// Примерная структура игрового цикла
function gameLoop() {
    update();  // Обновление состояния игры
    render();  // Отрисовка кадра
    requestAnimationFrame(gameLoop);
}
```

## Полезные советы

### Для начинающих:

1. **Начните с простого:**
   - Сначала создайте персонажа, который может двигаться
   - Добавьте платформы
   - Реализуйте прыжки и гравитацию
   - Затем добавьте коллизии

2. **Используйте Canvas API:**
   - Изучите базовые методы: `fillRect()`, `drawImage()`, `clearRect()`
   - Используйте `requestAnimationFrame()` для плавной анимации

3. **Разбивайте задачу на части:**
   - Движение персонажа
   - Физика и гравитация
   - Коллизии
   - Игровая логика

### Для продвинутых:

1. **Используйте ООП:**
   - Создайте классы для игровых объектов
   - Примените принципы инкапсуляции и наследования

2. **Оптимизация:**
   - Используйте объектные пулы для часто создаваемых объектов
   - Минимизируйте количество перерисовок

3. **Расширенный функционал:**
   - Система частиц для эффектов
   - Параллакс-скроллинг фона
   - Система сохранения прогресса

## Примеры промптов для нейросети

### 1. Создание базовой структуры

```
Создай структуру проекта для игры-платформера на чистом JavaScript с использованием Canvas API. Включи основные классы: Game, Player, Platform. Опиши назначение каждого файла.
```

### 2. Реализация персонажа

```
Напиши класс Player для игры-платформера на JavaScript. Класс должен включать методы для движения влево/вправо, прыжков, применения гравитации. Используй Canvas API для отрисовки.
```

### 3. Система коллизий

```
Реализуй систему обнаружения коллизий между прямоугольными объектами для платформера. Напиши функцию, которая проверяет столкновение персонажа с платформами и корректно обрабатывает их.
```

### 4. Игровой цикл

```
Создай игровой цикл для платформера используя requestAnimationFrame. Цикл должен обновлять состояние игры (физика, коллизии) и отрисовывать кадр на Canvas.
```

### 5. Обработка ввода

```
Напиши класс InputHandler для обработки нажатий клавиш в игре-платформере. Должна быть возможность отслеживать состояние клавиш (нажата/отпущена) для плавного управления.
```

### 6. Игровая логика

```
Реализуй систему подсчета очков и условий завершения игры в платформере. Добавь обработку сбора предметов и отображение счета на экране.
```
