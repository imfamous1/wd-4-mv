# Интерактивность с JavaScript

## Работа с формами в JavaScript

Формы — это главный способ получить данные от пользователя (логины, отзывы, заказы). Наша задача — научиться обрабатывать эти данные.

### Как подключиться к форме из JavaScript?

#### 1. Получить элемент формы

Самый простой способ — по его `id`:

```html
<!-- HTML -->
<form id="myForm">
  <input type="text" id="userName" name="username">
  <button type="submit">Отправить</button>
</form>
```

```javascript
// JavaScript
const formElement = document.getElementById('myForm');
```

#### 2. Подписаться на событие submit

Это событие происходит, когда пользователь нажимает кнопку "Отправить" или клавишу Enter в поле формы.

```javascript
formElement.addEventListener('submit', function(event) {
  // Эта функция выполнится при отправке формы
});
```

**Что такое `event`?**

`event` — это объект, который автоматически передается в функцию-обработчик браузером при возникновении события (в данном случае — отправки формы).

- Браузер создает его автоматически — когда пользователь нажимает кнопку отправки формы или вызывает `form.submit()`, браузер генерирует объект события submit
- Передается как первый аргумент — этот объект автоматически передается в вашу функцию-обработчик
- Доступен только внутри функции — вы получаете его как параметр функции

```javascript
console.log(event.type);      // 'submit'
console.log(event.target);    // элемент формы, который вызвал событие
console.log(event.timeStamp); // время возникновения события
```

### Как брать данные из формы?

#### Способ 1: Доступ через свойство формы по name

```javascript
// Доступ через свойство формы по name
console.log(myForm.username.value);
```

#### Способ 2: Через FormData (более современный способ)

```javascript
myForm.addEventListener('submit', function(event) {
  event.preventDefault();
  
  const formData = new FormData(myForm);
  console.log(formData.get('username'));
});
```

#### Способ 3: Прямой доступ к элементу по id

```javascript
formElement.addEventListener('submit', function(event) {
  // Останавливаем стандартную перезагрузку страницы
  event.preventDefault();
  
  // Достаем значение поля по его id
  const nameInput = document.getElementById('userName');
  const userName = nameInput.value; // Здесь лежит то, что ввел пользователь
  
  console.log('Пользователь ввел:', userName);
  // Теперь с этим значением можно работать: проверить, отправить на сервер и т.д.
});
```

**Ключевой момент**: `event.preventDefault()` — очень важная строка. Она предотвращает стандартное поведение браузера (перезагрузку страницы при отправке формы), позволяя нам обработать данные на месте с помощью JavaScript.

## Регулярные выражения (RegExp)

### Что это?

Регулярные выражения — это мощный инструмент для поиска и проверки текста по заданному шаблону. Представьте себе "умный поиск" или "маску" для строк.

### Откуда берутся?

Их не изобретают, а составляют по определенным правилам. Регулярка — это просто строка, но написанная по своим законам.

### Как составляются?

Записываются между символами `/.../`:

- `/\d/` — ищет одну цифру (d = digit)
- `/\w/` — ищет одну букву или цифру (w = word)
- `/[a-zA-Z]/` — ищет одну букву из заданного диапазона (латиница)
- `/.+/` — ищет один или больше любых символов
- `/{5,}/` — предыдущий символ должен повториться как минимум 5 раз

### Пример: Проверка email (упрощенная)

```javascript
const emailRegex = /^\S+@\S+\.\S+$/;
// ^ - начало строки
// \S+ - один или больше НЕ пробельных символов
// @ - собака
// \. - точка (экранируем, т.к. точка в regexp - особый символ)
// $ - конец строки

const userEmail = "student@example.com";
const isValid = emailRegex.test(userEmail); // Метод .test() возвращает true/false
console.log(isValid); // Выведет true
```

### Как они связаны с формами?

Чаще всего регулярные выражения используются для валидации (проверки) форм перед отправкой.

```javascript
formElement.addEventListener('submit', function(event) {
  event.preventDefault();
  
  const emailInput = document.getElementById('email');
  const userEmail = emailInput.value;
  const emailRegex = /^\S+@\S+\.\S+$/;
  
  if (!emailRegex.test(userEmail)) { // Если проверка НЕ пройдена
    alert('Пожалуйста, введите корректный email!');
    return; // Прерываем выполнение функции
  }
  
  // Если все хорошо, продолжаем (например, отправляем данные)
  console.log('Email корректен, можно отправлять!');
});
```

### Часто используемые регулярные выражения

```javascript
// Только цифры
const digitsOnly = /^\d+$/;

// Только буквы (латиница)
const lettersOnly = /^[a-zA-Z]+$/;

// Буквы, цифры, пробелы и знаки препинания
const textWithPunctuation = /^[a-zA-Zа-яА-Я0-9\s.,!?-]+$/;

// Телефон (упрощенный формат)
const phoneRegex = /^\+?[\d\s()-]+$/;

// Пароль (минимум 8 символов, хотя бы одна буква и цифра)
const passwordRegex = /^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{8,}$/;
```

## Хранилища в браузере

Зачем нужно? Чтобы запомнить данные о пользователе или его действиях прямо в браузере, чтобы после перезагрузки страницы всё не пропало.

### 1. LocalStorage (Локальное хранилище)

#### Что это?

Простое хранилище в виде "ключ-значение".

- **Объем**: ~5-10 МБ
- **Срок хранения**: Данные не имеют срока годности и не удаляются после закрытия браузера
- **Как работает**: Данные хранятся в виде строк. Чтобы сохранить объект, его нужно превратить в строку JSON

#### Основные команды:

```javascript
// Сохранить данные
localStorage.setItem('ключ', 'значение');
localStorage.setItem('userTheme', 'dark');

// Прочитать данные
const theme = localStorage.getItem('userTheme');
console.log(theme); // Выведет 'dark'

// Удалить данные
localStorage.removeItem('userTheme');

// Очистить всё
localStorage.clear();
```

#### Пример с объектом:

```javascript
const userSettings = { theme: 'dark', language: 'ru' };

// Сохраняем (превращаем объект в строку)
localStorage.setItem('settings', JSON.stringify(userSettings));

// Читаем (превращаем строку обратно в объект)
const savedSettings = JSON.parse(localStorage.getItem('settings'));
console.log(savedSettings.theme); // Выведет 'dark'
```

#### Обработка ошибок при работе с LocalStorage

```javascript
function saveToLocalStorage(key, value) {
  try {
    localStorage.setItem(key, JSON.stringify(value));
    return true;
  } catch (error) {
    console.error('Ошибка сохранения в LocalStorage:', error);
    return false;
  }
}

function getFromLocalStorage(key) {
  try {
    const item = localStorage.getItem(key);
    return item ? JSON.parse(item) : null;
  } catch (error) {
    console.error('Ошибка чтения из LocalStorage:', error);
    return null;
  }
}
```

### 2. Cookies (Куки)

#### Что это?

Небольшие строки данных (до ~4 КБ), которые браузер автоматически отправляет на сервер с каждым запросом.

**Главное отличие от LocalStorage**: Сервер может читать и записывать куки. LocalStorage — только клиентский.

#### Для чего раньше применялись?

Для хранения логинов, токенов, персональных настроек. Сейчас для многих задач используют LocalStorage, но куки незаменимы для работы с сервером.

**Минусы**: Ограниченный объем, неудобный API (в JavaScript с ними работать сложнее).

#### Почему все их собирают?

Это как пропуск. Представьте, что вы пришли в клуб. На входе вам ставят штамп на руку. С этим штампом вы можете выходить и заходить снова, и охрана будет вас узнавать. Куки — это такой цифровой штамп от сайта.

Они автоматически отправляются на сервер. В отличие от LocalStorage, браузер всегда отправляет куки этого сайта на сервер с каждым запросом. Это их главная суперсила.

Зашли на сайт → браузер отправил куки с вашим логином → сайт вас узнал и показал личный кабинет. Всё автоматически!

#### Почему их боятся принимать?

**Следящие куки (Tracking Cookies)**. Это главная причина.

Допустим, вы зашли на сайт example.com и увидели там рекламный баннер от компании ad-network.com. Этот баннер может поставить вам куки от своего домена (ad-network.com).

Потом вы перешли на другой сайт, где тоже есть баннер от ad-network.com. Ваш браузер отправляет куки ad-network.com обратно к ним.

Так рекламная сеть начинает узнавать вас на разных сайтах и строить ваш "портрет": что вы ищете, что вам нравится. Потом это используется для таргетированной рекламы.

#### Есть ли опасность? Стоит ли их принимать?

- **Прямой вирус через куки** — почти невозможен. Это просто текстовые файлы, а не исполняемый код.
- **Главная "опасность"** — это вторжение в приватность. Кому-то может не понравиться, что за ним следят и собирают о нем данные без явного согласия.

#### Когда куки необходимы?

- **Сессии и авторизация**. Без куки большинство сайтов просто не смогут вас "запомнить". Вы будете постоянно выходить из всех аккаунтов.
- **Настройки сайта**. Язык, тема, регион — всё это удобно хранить в куках.

#### Итог: принимать ли куки?

**Да, но с умом.**

- На знакомых и доверенных сайтах (ваш банк, почта, соцсети) — смело принимайте, иначе они не будут работать правильно.
- На незнакомых сайтах можно посмотреть настройки. Часто можно отказаться от "рекламных" или "статистических" куки, приняв только "необходимые".

#### Регулирование в разных странах

**🇷🇺 В России и некоторых других странах:**

- Закон о персональных данных №152-ФЗ — менее строгий в отношении cookies
- Технические cookies можно ставить без согласия
- "Согласие получено неявно" — часто считается, что продолжение использования сайта = согласие
- Практика исполнения — менее строгое регулирование

**🇪🇺 В Европе (GDPR):**

- Требуется явное согласие ДО установки любых tracking cookies
- Штрафы до 4% глобального оборота компании
- "Opt-in" подход — пользователь должен явно согласиться

**🇺🇸 В США (CCPA/CPRA):**

- "Opt-out" подход — cookies ставятся, но пользователь может отказаться
- Обязательная кнопка "Do Not Sell My Personal Information"

#### Работа с Cookies в JavaScript

```javascript
// Установка cookie
function setCookie(name, value, days) {
  const expires = new Date();
  expires.setTime(expires.getTime() + (days * 24 * 60 * 60 * 1000));
  document.cookie = `${name}=${value};expires=${expires.toUTCString()};path=/`;
}

// Получение cookie
function getCookie(name) {
  const nameEQ = name + "=";
  const ca = document.cookie.split(';');
  for (let i = 0; i < ca.length; i++) {
    let c = ca[i];
    while (c.charAt(0) === ' ') c = c.substring(1, c.length);
    if (c.indexOf(nameEQ) === 0) return c.substring(nameEQ.length, c.length);
  }
  return null;
}

// Удаление cookie
function deleteCookie(name) {
  document.cookie = `${name}=;expires=Thu, 01 Jan 1970 00:00:00 UTC;path=/;`;
}
```

## Таймеры и интервалы

Позволяют выполнить код не сейчас, а через какое-то время или многократно с повтором.

### setTimeout — выполнить действие один раз, через заданное время

```javascript
// Синтаксис: setTimeout(функция, задержка_в_миллисекундах);
setTimeout(function() {
  console.log('Это сообщение появилось через 2 секунды!');
}, 2000); // 2000 мс = 2 секунды
```

**Пример из жизни**: Показать всплывающее окно "Подпишитесь на нашу рассылку!" через 10 секунд после загрузки страницы.

```javascript
window.addEventListener('DOMContentLoaded', function() {
  setTimeout(function() {
    alert('Подпишитесь на нашу рассылку!');
  }, 10000); // 10 секунд
});
```

### setInterval — выполнять действие повторно, с заданным интервалом

```javascript
// Синтаксис: setInterval(функция, интервал_в_миллисекундах);
const timerId = setInterval(function() {
  console.log('Эта строка появляется каждую секунду!');
}, 1000);

// Как остановить интервал?
// clearInterval(timerId);
```

**Пример из жизни**: Создание обратного отсчета на странице, обновление курса валют каждые 30 секунд.

```javascript
// Пример обратного отсчета
let countdown = 10;
const timerId = setInterval(function() {
  console.log(`Осталось: ${countdown} секунд`);
  countdown--;
  
  if (countdown < 0) {
    clearInterval(timerId);
    console.log('Время вышло!');
  }
}, 1000);
```

### Очистка таймеров

Важно всегда очищать таймеры, когда они больше не нужны, чтобы избежать утечек памяти:

```javascript
// Сохраняем ID таймера
const timeoutId = setTimeout(function() {
  console.log('Это не выполнится');
}, 5000);

// Отменяем таймер
clearTimeout(timeoutId);

// Для интервалов
const intervalId = setInterval(function() {
  console.log('Повторяется');
}, 1000);

// Останавливаем интервал
clearInterval(intervalId);
```
